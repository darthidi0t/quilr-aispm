# Quilr AISPM Console — interactive mockup

A clickable, single-file mockup of an AI Security Posture Management (AISPM) console in the Quilr dark theme.

Open `index.html` in any browser. There is no build step and nothing to install.

## Modules

- **Overview:** estate risk tiles and findings, all clickable.
- **Inventory:** 432 AI assets with source and type filters, a service catalog, workload analysis and cloud telemetry (VPC, subnet, IP, tags).
- **Posture:** CSPM and DSPM (data assets, issues and data threats).
- **AI security:** AI Posture, Model security, Data protection and Identity.
- **AI Gateway:** runtime events, plus the MCP gateway with agentic identity and tool-call guardrails.
- **Compliance, Observability (end-to-end lineage), Supply chain and Attack paths.**
- **Policies:** a QuilrQL policy library, a new-policy builder and framework template packs.
- **Shadow AI:** workforce use, plus cloud flow-log discovery.
- **Setup & connectors:** IAM roles, cloud accounts and SaaS connectors.

## Data

All data is fictional. It was generated for a made-up bank, "Northwind Finance". No real customer, asset or event data is included.
